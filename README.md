# Motor Studio

### An interactive automotive cockpit concept

Motor Studio is a concept exploring how a modern vehicle cockpit can bring navigation, vehicle information, controls, alerts, and driving modes together in one connected experience.

The project focuses on making complex information easier to understand through clear visual hierarchy, contextual information, meaningful interaction, and responsive feedback.

## Design

The cockpit was designed in Figma using components, variants, variables, Auto Layout, prototyping, and animations.

Rather than designing isolated screens, I focused on creating a connected system where interactions and changes in context influence the interface.

The concept explores questions such as:

- How should information be prioritised while driving?
- How can controls feel simple without hiding important functionality?
- How can visual feedback make system changes easier to understand?
- How can different driving contexts influence the interface?

## Explore the Concept

The web experience allows the cockpit to be explored interactively.

Try the navigation, vehicle controls, alerts, and different driving modes. Click through the screens, adjust controls, and follow the prompts to see how the interface responds.

Some visual elements are presented as exported assets from the original Figma design to maintain visual fidelity, while the overall experience connects the different screens, states, and interactions.

**Everything is connected.**
